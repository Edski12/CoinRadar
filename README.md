# CoinRadar
CoinRadar solves a simple problem: keeping track of multiple forex pairs and crypto assets manually is tedious, and most free tools either show live prices without history or require a paid subscription for alerts. CoinRadar ingests price data on a schedule, stores it as queryable time-series data, and proactively notifies you when something moves — rather than requiring you to keep checking.
The system is built and operated end-to-end as a single-developer DevOps project: a Dockerized web dashboard runs on EC2, backed by RDS for persistent price history and watchlist data. A scheduled Lambda function handles price ingestion from public market APIs (CoinGecko for crypto, exchangerate-api for forex) and inline threshold checking for alerts, while a second scheduled Lambda compiles and emails a daily market digest via SES. The entire deployment pipeline — build, containerize, push to ECR, deploy to EC2 — is automated through GitHub Actions, with OIDC-based authentication instead of static AWS credentials.
CoinRadar isn't just a price tracker — it's a demonstration of designing, securing, deploying, and operating a production-style cloud system independently, covering compute, storage, serverless, networking, and CI/CD in a single cohesive project.
